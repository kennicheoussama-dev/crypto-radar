# 📊 Crypto Radar | رادار العملات

**Crypto Radar** هو تطبيق ويب تقدمي (PWA) خفيف وسريع لمتابعة أسعار العملات الرقمية في الوقت الفعلي. واجهة عربية مصممة خصيصاً للهواتف والكمبيوتر، وتعتمد على بيانات Binance العامة.

## ✨ المميزات
- **أسعار لحظية:** تحديث تلقائي للأسعار كل 15 ثانية.
- **رسوم بيانية مصغرة:** رسم بياني لكل عملة يوضح حركة السعر.
- **قائمة مخصصة:** إضافة وحذف العملات التي تهمك (يتم حفظها على جهازك).
- **تنبيهات أسعار:** إشعارات منبثقة، صوتية، واهتزاز عند عبور السعر لهدف محدد.
- **يعمل بدون إنترنت (جزئياً):** واجهة التطبيق تُفتح حتى لو انقطع الاتصال.
- **قابل للتثبيت:** يمكن تثبيته كتطبيق مستقل على أندرويد و iOS.
